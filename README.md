# Pagina-web-responsiva
Repositorio donde se creará una página web responsiva para todos los dispositivos. Proyecto final del módulo *Fundamentos del Desarrollo Web* del curso Frontend de **DEV.F**.

## Descripción
Este repositorio contiene una página HTML la cual es un portafolio personal de mis proyectos realizados durante el curso Frontend de **DEV.F**. También incluye información personal y un formulario de contacto.

## Características
Esta página web se adapta a cualquier dispositivo. Se utilizaron herramientas como media queries, flexbox y grid para un diseño adaptable y profesional, entre otros estilos. Se agregó una barra de navegación que se transforma en un menú hamburguesa en dispositivos móviles y un footer que incluye mis redes sociales. Se agregó un mensaje de cookies el cual se quita al dar click en aceptar o rechazar.
